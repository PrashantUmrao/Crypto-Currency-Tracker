A modern real-time cryptocurrency dashboard that helps users track market data, analyze trends, and manage watchlists in a clean responsive interface. The project also includes an AI Coach chatbot module designed to help users learn crypto fundamentals; however, the current version is a preliminary implementation and is not fully functional yet. Active development is ongoing, and a complete AI-powered conversational assistant will be integrated soon.

This project combines live market analytics + beginner education, making it useful for both traders and newcomers to cryptocurrency while continuously evolving with upcoming intelligent features.

🚀 Features
📊 Live Market Data
Real-time cryptocurrency prices (CoinGecko API)
24h change, market cap & volume
BTC dominance & global market stats
Automatic refresh every 2 minutes

📈 Analytics & Insights
Market trend detection (Bullish / Bearish / Neutral)
Volatility index calculation
Investor sentiment analysis
Market momentum indicator
Trending coins detection

⭐ Watchlist System
Add/remove favorite coins
Persistent storage using LocalStorage
Quick access to tracked assets

🪙 Coin Details Panel
Detailed stats per coin
Interactive charts (Price / Volume / Market Cap)
7-day historical visualization (Chart.js)

🤖 AI Crypto Coach
Built-in learning assistant that helps users understand:
Cryptocurrency basics


📉 Market Trends Section
Trending coins
Sentiment chart
Investment opportunity suggestions

🎨 Extra Utilities
Light/Dark theme toggle
Search & filter coins
Pagination system
Export data to CSV

This project was built to create a complete crypto learning + tracking platform instead of just a price viewer.
It focuses on:
Helping beginners understand crypto

Simulating a premium dashboard experience
